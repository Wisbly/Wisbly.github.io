## ⚠️ Regla base antes de todo

**Bain es una consultora global de USD 6 mil millones al año.** Wisbly Labs es un estudio unipersonal chileno. Copiar el "premium consulting look" 1:1 hace que suenes falso: dueños de pyme chilena huelen el fake al toque. Lo que sí funciona es **adoptar la estructura y disciplina** de Bain, pero con voz honesta, escala real y tono chileno.

**La regla:** patrones sí, poses no.

---

## 🎯 Lo que Bain hace bien (y podemos adaptar)

| Patrón Bain | Por qué funciona | Adaptación Wisbly Labs |
|---|---|---|
| Hero con **misión bold**, no lista de servicios | Comunica postura, no catálogo | Sí — "Construimos software para las pymes chilenas que trabajan como en 2001" |
| **Casos con cifras concretas** ("$300M saved") | Data > adjetivos | Sí — "Cine independiente vende 47 entradas un domingo a las 22:15" (evento real futuro) |
| Navegación estructurada: **Industrias · Servicios · Insights · About** | Facilita comprensión rápida del abanico | Sí — pero simplificada: "Productos · Servicios · Blog · Nosotros" |
| **Preguntas al lector** ("What can we help you achieve?") | Personaliza y engancha | Sí en tono chileno: "¿Qué está frenando tu pyme?" |
| **Insights como content authority** | Posiciona como expertos vs vendedores | Sí — blog con contenido útil para pymes chilenas |
| **Visual restraint** (blanco, tipografía, foto pro) | Contraste con agencias saturadas | Sí — Wisbly hereda esta disciplina (paleta oscura Butaca sirve bien) |
| **Trust signals estructurados** (logos, cifras, reconocimiento) | Reduce riesgo percibido | Sí — pero con las señales reales tuyas: TingGo, primeros clientes, capital Sercotec |
| **Newsletter signup con propósito claro** | Convierte lectores en leads | Sí — "1 email al mes con lo que aprendimos construyendo software para pymes" |
| **CTA principal repetido** ("LET'S GET TO WORK") | Bajo la vista siempre | Sí — CTA "Conversemos" u "Agenda 20 min" reforzado |

## 🏗️ Estructura propuesta para wisbly.cl

Diez secciones inspiradas en Bain pero escaladas a tu realidad. Cada sección incluye copy inicial listo para trabajar.

### 1 · Nav bar
```
Izquierda:   [Wisbly.] logo
Centro:      Productos · Servicios · Casos · Blog · Nosotros
Derecha:     [Conversemos] botón primario
```

**Dif vs Butaca:** navegación de STUDIO (múltiples productos + servicios) vs navegación de PRODUCTO (Butaca solo cines).

### 2 · Hero
**Kicker:** ESTUDIO CHILENO DE SOFTWARE Y WEB PARA PYMES

**Headline:**
> Construimos el software y las páginas web
> para las pymes chilenas que aún trabajan como en *2001*.

**Subhead:**
> Somos un estudio pequeño desde Valparaíso. Hacemos dos cosas bien: productos SaaS verticales (como Butaca para cines) y páginas web + software a medida para pymes concretas. Cero jerga, cero promesas de "transformación digital".

**CTAs:**
- Primario: [Conversemos · 20 min]
- Secundario: [Ver nuestro trabajo]

**Visual:** foto documental en b&n de Cristian trabajando (Vallenar / Valparaíso) o composición tipográfica editorial en fondo oscuro. NO stock.

**Patrón Bain adaptado:** hero con misión bold, no feature-list.

### 3 · Productos (verticales SaaS)
**Fondo:** cream editorial

**Kicker:** LO QUE CONSTRUIMOS

**H2:** *Software vertical que resuelve un problema real, no una moda.*

**Body:** Construimos productos SaaS mensuales cuando encontramos un vertical donde el software actual no funciona para pymes chilenas. Empezamos con uno.

**Card 1 · BUTACA** (destacada)
- Logo Butaca
- Descripción: "Software para cines y salas culturales independientes de Chile. Panel de administración + Transbank + web pública lista."
- Estado: "Lanzando 2026" o "10 cines activos" (cuando aplique)
- Link: butaca.app
- Foto/mockup dashboard

**Card 2 · [PLACEHOLDER] · próximo producto**
- "Próximo producto en evaluación"
- Placeholder visual

**Patrón Bain adaptado:** en Bain son "Industries" (25). En Wisbly Labs son "Productos" (1-2 reales, más placeholder futuro). Nunca inflar.

### 4 · Servicios (custom)
**Fondo:** dark

**Kicker:** LO QUE HACEMOS A MEDIDA

**H2:** *Cuando el software estándar no calza, lo hacemos.*

**Body:** Para pymes chilenas específicas que necesitan una web o software que ninguna plantilla resuelve bien. Trabajamos por proyecto, no por hora.

**Grid 4 servicios:**

| Servicio | Descripción corta |
|---|---|
| 🌐 **Páginas web pymes** | Web con SEO local, formulario de contacto, blog. Pensada para vender, no para lucirse. |
| 🛒 **E-commerce a medida** | Tienda online con pasarela chilena (Webpay/Onepay/Fintoc), gestión de inventario, envíos. |
| ⚙️ **Software interno** | Herramientas internas para tu operación: reservas, planillas reemplazadas por app, gestión de personal. |
| 🔍 **SEO + contenido** | Rankeo local en Google para tu ciudad + escribimos el contenido que te ayuda a rankear. |

**Verticales donde ya trabajamos:**
- Cines independientes (via Butaca)
- Pastelerías [cuando exista el cliente]
- Cafeterías [cuando exista]
- Otras pymes chilenas (a demanda)

**Patrón Bain adaptado:** en Bain son "Consulting Services" (12+). En Wisbly Labs son "Servicios" (4 core), sin exageración.

### 5 · Casos (proof)
**Fondo:** cream

**Kicker:** CASOS

**H2:** *Cifras reales de cosas que hicimos.*

**Body:** Solo mostramos casos que están vivos. Sin humo, sin renders inventados.

**Card por caso (cuando exista):**
- Logo cliente (o nombre del cine/pastelería/pyme)
- Cifra ancla: "47 entradas vendidas online un domingo 22:15" o "80% menos tiempo armando reporte mensual"
- 2 líneas de contexto
- CTA: "Ver caso completo →"

**Placeholder honesto mientras no hay casos:**
> "Nuestro primer caso público será [Nombre cine] en octubre 2026. Mientras tanto, agenda una demo y te contamos qué estamos construyendo."

**Patrón Bain adaptado:** Bain muestra 4 casos con cifras enterprise. Tú muestras 1-3 casos con cifras pyme. La cifra manda, no la marca del cliente.

## 🎨 Sistema visual sugerido

**Recomendación:** heredar la paleta dark-first de Butaca (`../butaca_branding/BUTACA-BRAND-GUIDELINES.md`). Consistente con la marca-producto, refuerza que Butaca es hijo de Wisbly Labs. Cambios:

- **Rojo terciopelo `#8B1A2B`** → **Wisbly Red igual** (unifica todo el ecosistema)
- **Dorado luz `#E4B366`** → mantener
- **Negro sala `#0A0806`** → mantener
- **Crema butter `#F1E9D2`** → mantener

**Diferenciación entre butaca.app y wisbly.cl:**
- Butaca: usa más el rojo terciopelo (marca-producto vibrante)
- Wisbly: usa más el negro + dorado (studio matriz más sobrio y editorial)

Tipografía: **misma que Butaca** (Fraunces + Inter + JetBrains Mono). Consistencia entre matriz e hijos.

**Foto/imagery:** documental b&n o duotone rojo Wisbly. Cero stock, cero ilustraciones vector genéricas.

## 🛠️ Cómo construir esto (recomendación stack)

**Opción rápida (recomendada para arrancar):**
- **Framework:** Astro (SSG estático, súper rápido)
- **CSS:** Tailwind con las variables ya definidas en BUTACA-BRAND-GUIDELINES.md
- **Hosting:** Vercel o Cloudflare Pages (gratis)
- **Formulario contacto/newsletter:** Formspree o Web3Forms (gratis hasta 50/mes)
- **Blog:** MDX en el mismo repo (posts en `/blog/*.mdx`)
- **Tiempo estimado build v1:** 6-10h de trabajo si copio HTML puro estilo Butaca, más si es Astro con MDX

**Opción incremental:**
1. Semana 1: HTML/CSS puro (como los HTMLs de Butaca), 1 archivo `index.html` + `sobre.html`
2. Semana 2-4: migrar a Astro cuando quieras blog
3. Mes 2: primer post blog + newsletter automático
